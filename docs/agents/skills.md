Source: https://github.com/mattpocock/skills, pinned upstream `49dd158d1076134a641b33efb035946536778336`. MIT license is at `.agents/skills/MATT-POCOCK-LICENSE.txt`. Copied stable engineering and productivity SKILL.md and companion files into this repository. Existing `frontend-design` remains unchanged. This is guidance for compatible coding agents, not a runtime dependency. Slash commands require an agent supporting installed skills; GitHub Jules and browser ChatGPT may treat them as instructions only.

GitHub Issues, default triage labels and domain document conventions are configured under `docs/agents/`. Check labels exist before running triage. To update, review new upstream content and scripts before making a version-pinned PR.
