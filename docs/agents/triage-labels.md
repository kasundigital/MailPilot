# Triage labels

Proposed role-to-label mapping; verify/create labels on GitHub before `/triage`:

| Role | Label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Use `bug` or `enhancement` as the issue type. Map existing equivalent labels rather than duplicating them.
